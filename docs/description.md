Мы с моим племянником делаем проект: мобильный робот на гусеничной платформе, который может считывать QR-коды с командами (ехать вперёд/назад/развернуться и т.д.) и выполнять их.
Железная часть у нас уже собрана и подключена, теперь нужено разработать sofware и firmware для управления роботом.

Hardware, которое мы используем в проекте:
    - Raspberry Pi 4B на 4GB RAM (или 8GB, точно не помню);
    - Микроконтроллер Raspberry Pi Pico (на основе RP2040);
    - плата управления моторами для Raspberry Pi Pico от Waveshare (Waveshare Pico-Motor-Driver, https://www.waveshare.com/wiki/Pico-Motor-Driver?srsltid=AU7gw4V3d6JILQItUSdEOHcIXEipsTN_ly0o0ccx0ZS4Ubtn_52Vfi5W)
    - два двигателя на 12В с магнитными энкодерами;
    - USB-камера;
    - power bank на 12 вольт для управления двигателями;
    - отдельный power bank для питания Raspberry Pi 4B через USB type C;
    - Raspberry Pi 4B и Raspberry Pi Pico соединены между собой через пины UART (через пины);
