# Прошивка Pico

Прошивка управляет двумя гусеницами по UART-протоколу V1 из
`docs/robot_architecture_ru.md`. Энкодеры пока не используются; PWM не является
измеренной скоростью. Пошаговая инструкция для Thonny и пояснение файлов —
в §3.8 `docs/robot_guide_ru.md`.

1. Заполните `config.py` по паспорту проводки. `None` в обязательном поле
   запрещает запуск. Нельзя считать контакты, адрес, частоту и моторные клеммы
   из примера Waveshare подтверждёнными для вашего робота.
2. С отключённым питанием моторов установите MicroPython на Pico и откройте
   его USB Shell в Thonny. Скопируйте сначала `protocol.py` и `boot_counter.py`
   в корень памяти Pico.
3. Один раз выполните в USB Shell `from boot_counter import initialize`, затем
   `initialize()`. Это создаст `boot0.dat`. При обновлениях журнал не стирайте.
4. Скопируйте `config.py`, `pca9685.py`, `motor_driver.py`, `motion.py` и
   `controller.py`. Проверьте `import config; config.validate()` в USB Shell.
5. Последним скопируйте `main.py` и перезапустите Pico без питания моторов.
   Он выключает каналы и ждёт HELLO/ARM от Pi, но не запускает мотор сам.

Рабочий GPIO UART: 115200, 8N1. USB REPL нужен только для настройки и
диагностики. Pico ограничивает движение 30% PWM и 2000 мс на шаг, а отсутствие
нового HEARTBEAT в течение 500 мс вызывает попытку остановки. STOP также
отзывает сеанс. При сбое I²C команда выключения может не дойти до PCA9685;
первые моторные проверки проводите с поднятыми гусеницами и доступным
отключением питания моторов.

Программные тесты без Pico: `python -B -m unittest discover -s tests -p 'test_pico_*.py'`.
