# Прошивка Pico

Модули в этой папке реализуют управление двумя гусеницами по протоколу V1 из
`docs/robot_architecture_ru.md`. Энкодеры не используются; PWM не является
измеренной скоростью. Исходный пример Waveshare оставлен отдельно.

Перед копированием файлов на Pico заполните `config.py` по паспорту проводки:
I²C и перемычки, адрес PCA9685, частоту PWM, моторные клеммы, физическое
направление и инверсию обеих сторон, UART, паузу смены направления и ограничение
разгона. Пока поле не заполнено, `main.py` отказывает в запуске. Параметры
движения ограничены 30% и 2000 мс; менять их можно только после проверки
аппаратуры. Не запускайте демонстрацию из исходного `PCA9685.py`.

После установки MicroPython, **с отключённым питанием моторов**, один раз
инициализируйте журнал счётчика через USB REPL:

```python
from boot_counter import initialize
initialize()
```

Затем скопируйте все `.py` файлы этой папки в корень файловой системы Pico.
`main.py` запускается при старте, явно выключает выходы и ожидает HELLO/ARM.
Рабочие команды приходят только через GPIO UART, 115200 8N1. USB REPL служит
для диагностики. START на Pi должен создавать новый HELLO с новым nonce.

Программный STOP, таймер шага и таймер связи отправляют выключение через I²C.
PCA9685 сохраняет состояние отдельно от Pico; при отказе I²C или перезапуске
Pico без аппаратного запрета выходы могут оставаться активными. Первые проверки
проводите с поднятыми гусеницами и доступным отключением питания моторов.

Программная проверка без Pico: `python -B -m unittest discover -s tests -p 'test_pico_*.py'`.
